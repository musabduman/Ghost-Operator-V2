# FlightSim

Basit bir uçuş simülatörü prototipi. Python ve Pygame kullanılarak geliştirilmiştir.

## Kurulum
```
pip install -r requirements.txt
```

## Çalıştırma
```
python src/main.py
```

## Özellikler
- Temel uçak kontrolü (yön tuşları)
- Basit fizik ve aerodinamik
- Placeholder ortam ve pist

## Katkıda Bulunma
Kodları geliştirmek, yeni modeller eklemek veya fizik iyileştirmeleri yapmak için serbestsiniz.
